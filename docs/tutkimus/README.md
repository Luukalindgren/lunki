# Tutkimusten kuvat

Ehdotus- ja `Tutki lisää` -issueiden kuvat vaihtoehdoista, hakemisto issuen
numeron mukaan (`docs/tutkimus/<N>/`). Issuet näyttävät kuvat
raw.githubusercontent-osoitteilla. Kuvat ovat mockupeja: ne havainnollistavat
vaihtoehtoja eivätkä ole pelin nykyistä koodia.

# Kansikuvat

LinkedIn-kansikuvat (1584×396 px) Lunkinjärveltä kelluntarenkaan POV-näkymästä
ilman HUDia, samalla tyylillä kuin linkkien jakokuva
(`packages/client/public/esikatselu.png`). Kansio on buildin ulkopuolella, joten
kuvat eivät päädy pelin bundleen.

| Kuva                                                   | Kuvaus                                           |
| ------------------------------------------------------ | ------------------------------------------------ |
| [1-ilta-aurinko.png](1-ilta-aurinko.png)               | Ilta, aurinko ja sen kimallus vedessä            |
| [2-ilta-rusko.png](2-ilta-rusko.png)                   | Sama näkymä myöhemmin, aurinko puiden takana     |
| [3-ilta-rengas-ja-vapa.png](3-ilta-rengas-ja-vapa.png) | Ilta, rengas ja vapa näkyvissä kuten jakokuvassa |
| [4-aamu-saaret.png](4-aamu-saaret.png)                 | Järven keskiosan saaret aamuauringossa           |
| [5-paiva-saaret.png](5-paiva-saaret.png)               | Päivä, saaria ja mökki rannalla                  |
| [6-yo-kuutamo.png](6-yo-kuutamo.png)                   | Täysikuu yöllä                                   |

[esikatselu.png](esikatselu.png) näyttää kaikki kuvat ja profiilikuvan
likimääräisen paikan LinkedInissä (vasen alakulma).

Kuvat tehdään uudelleen skriptillä `scripts/kansikuva/renderoi.mjs`; kuvakulmat,
kellonajat ja rajaukset ovat tiedostossa `scripts/kansikuva/kuvat.json`. Ohje on
skriptin alussa.
